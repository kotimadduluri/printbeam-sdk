ScanListener

interface ScanListener

Receives the events of one PrintBeam.scan. Every callback is dispatched on the main dispatcher, so implementations may touch UI state directly.

onFinished

abstract fun onFinished(printers: List<DiscoveredPrinter>)

The scan ran to completion (timeout elapsed or every source finished). printers is the final deduplicated snapshot, one entry per unique id with its best-known merged fields. Not invoked when the scan is cancelled — via ScanHandle.cancel, a newer PrintBeam.scan, PrintBeam.connect, or PrintBeam.shutdown.

abstract fun onPrinterFound(printer: DiscoveredPrinter)

A printer was located. May fire more than once for the same DiscoveredPrinter.id when a later source enriches an earlier observation (port-scan finds a bare endpoint, mDNS then resolves its name) — the re-emission carries the merged entry. Key UI lists by DiscoveredPrinter.id so enrichment replaces rather than appends.
