printbeam/dev.printbeam.sdk/PrintBeamConfig/PrintBeamConfig

PrintBeamConfig

constructor(context: PrinterContext, logger: PrinterLogger = PrinterLogger.NoOp, connectionFactory: ConnectionFactory = DefaultConnectionFactory(logger), defaultPaperWidth: PaperWidth = PaperWidth.MM_80)

Parameters

context

Platform handle. On Android construct with the application Context (PrinterContext(applicationContext)); on iOS no argument is needed (PrinterContext()). Required for BLE connections and for discovery; the facade shares one instance across both so iOS peripheral identity survives the scan-to-connect handoff.

logger

Sink for library breadcrumbs (discovery, connection negotiation, transports). Defaults to PrinterLogger.NoOp — the library writes nothing unless a sink is supplied.

connectionFactory

Override only for tests — defaults to DefaultConnectionFactory wired with logger. Custom factories own their own logging.

defaultPaperWidth

Paper width assumed for printers registered by scanning and for PrintBeam.addManualPrinter calls that don't specify one.
