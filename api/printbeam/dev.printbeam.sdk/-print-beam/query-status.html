queryStatus

suspend fun queryStatus(printerId: String): PrinterStatus?

Query real-time printer status (ESC/POS DLE EOT) over printerId's held session, auto-connecting (scan cancelled first, state via PrinterState.Connecting) when none is live — exactly like print. Serializes with prints to the same printer, so a status query never interleaves bytes with a receipt.

Returns null only when the printer sends no reply within the read window — common for BLE printers that don't implement the read path. Transport failures (connect, write, genuine read errors) propagate as PrinterException; the held session is left in place, and a dead link surfaces on the next print, whose reopen-retry path recovers it.

Prefer this over dev.printbeam.Printer.queryStatus when using the facade: the L1 path opens its own connection next to the held one — on BLE a whole extra GATT handshake.

Throws

PrinterException.NotInitialized

when the facade is not initialized.

PrinterException.InvalidInput

for an unknown id.

fun queryStatus(printerId: String, onResult: (PrinterStatus?, PrinterException?) -> Unit)

Callback twin of queryStatus: runs in the facade scope, delivers (status, null) on success — a null status meaning the printer sent no reply — or (null, failure) when the query failed, on the main dispatcher.
