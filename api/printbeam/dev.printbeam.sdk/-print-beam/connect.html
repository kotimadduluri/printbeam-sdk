connect

suspend fun connect(printerId: String)

Open and hold a connection for printerId. No-op if a session is already held. Opening cancels any active scan first — the iOS shared CBCentralManager has a single delegate slot, so scanning and connecting must not overlap; the facade owns that serialization so consumers never see the constraint.

State: PrinterState.Connecting while opening, then PrinterState.Connected; a failed open sets PrinterState.Failed and rethrows.

Failure reporting is deliberately split across the facade: connect throws — a failed open is an error of this call — while print reports transport failures as PrintResult.Failure, the outcome of a job that ran.

Parameters

printerId

Id from scan results, addManualPrinter, or rememberPrinter.

Throws

PrinterException.NotInitialized

when the facade is not initialized.

PrinterException.InvalidInput

for an unknown id.

PrinterException

when the transport open fails.

fun connect(printerId: String, onResult: (PrinterException?) -> Unit)

Callback twin of connect: runs in the facade scope, delivers null on success or the PrinterException on failure, on the main dispatcher. Not invoked if shutdown tears the facade down first.
