queryDeviceInfo

suspend fun queryDeviceInfo(printerId: String): DeviceInfo

Query printerId's identity over the held session via ESC/POS GS I n — manufacturer, model, firmware, serial. Fields the printer ignores come back null; DeviceInfo.isEmpty is true when it ignored all four (typical for BLE printers). The main consumer use is naming printers the scan couldn't: a port-scan-only network printer has no mDNS name, but often answers GS I with its model.

Same session semantics as queryStatus: reuses the held connection (opens one if needed), transport failures propagate as PrinterException and leave the session for the next print's reopen-retry to recover.

Throws

PrinterException.NotInitialized

when the facade is not initialized.

PrinterException.InvalidInput

for an unknown id.

fun queryDeviceInfo(printerId: String, onResult: (DeviceInfo?, PrinterException?) -> Unit)

Callback twin of queryDeviceInfo: runs in the facade scope, delivers (info, null) on success or (null, failure) when the query failed, on the main dispatcher.
