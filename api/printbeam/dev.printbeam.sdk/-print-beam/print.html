print

suspend fun print(printerId: String, block: ReceiptBuilder.() -> Unit): PrintResult

Build a receipt with block and print it on printerId's held session, auto-connecting (scan cancelled first, state via PrinterState.Connecting) when none is live. The paper width comes from the printer's registry entry, so line wrapping matches what scan or addManualPrinter recorded.

Link-drop policy: a write failure on a held connection closes it, reopens once, and retries the write once. If the retry fails the result is PrintResult.Failure, the session is fully closed, and state becomes PrinterState.Failed — a session is never left half-open.

Failure reporting is deliberately split across the facade: transport failures — the auto-connect failing included — are the outcome of a print job that ran, reported as PrintResult.Failure; only builder validation (e.g. invalid barcode data) throws. connect, by contrast, throws on failure: a failed open is an error of that call.

Throws

PrinterException.NotInitialized

when the facade is not initialized.

PrinterException.InvalidInput

for an unknown id or invalid receipt content.

fun print(printerId: String, block: ReceiptBuilder.() -> Unit, onResult: (PrintResult) -> Unit)

Callback twin of print: runs in the facade scope, delivers the PrintResult on the main dispatcher. Builder validation errors, which the suspend variant throws, arrive here as PrintResult.Failure — an async callback has no throw channel.
