rememberPrinter

fun rememberPrinter(printer: DiscoveredPrinter, paperWidth: PaperWidth? = null): String

Register a printer object the consumer already holds — typically a scan result restored from persistence — and return its stable id. When the id is already registered the two observations merge field-by-field (the same source-priority merge discovery uses), so remembering a printer never erases richer metadata the registry already has; printer's fields win ties.

This is the persistence round-trip: DiscoveredPrinter.id alone cannot be parsed back into an endpoint, so persist the printer's endpoint and fields, rebuild the DiscoveredPrinter, and hand it back here on the next launch — the returned id is identical every time.

Parameters

paperWidth

Paper the printer is loaded with; null keeps a width already registered for this id, falling back to PrintBeamConfig.defaultPaperWidth.
