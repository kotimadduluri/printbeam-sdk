BluetoothPermissions

object BluetoothPermissions

Runtime BLE permissions consumers must request before using the library's BLE discovery / connection. The set is API-level aware:

  • Android 12+ (API 31+): Manifest.permission.BLUETOOTH_SCAN + Manifest.permission.BLUETOOTH_CONNECT

  • Pre-12 (API ≤ 30): Manifest.permission.ACCESS_FINE_LOCATION (required by BluetoothLeScanner even though we're not deriving location — a long-standing Android quirk).

The library's manifest already declares the entries; consumer apps only need to call requestPermissions(BluetoothPermissions.required(), …) and wait for the user response.

Network printers don't need any of these — only INTERNET, which is normal.
