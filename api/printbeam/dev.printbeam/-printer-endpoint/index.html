PrinterEndpoint

sealed class PrinterEndpoint

Where to reach a printer. The canonical key passed into Printer for any operation and into dev.printbeam.discovery.DiscoveredPrinter when an endpoint is found by scanning.

Each subtype carries everything the dev.printbeam.connection.PrinterConnection needs to dial — host/port for Network, device-id + GATT profile for Ble.

The transport set is sealed by design: consumers rely on exhaustive when over endpoints, and new transports (USB, Bluetooth Classic) arrive as library releases that update the documented dispatch sites in lockstep. Third-party transports plug in at the connection level via dev.printbeam.connection.ConnectionFactory — never by extending this hierarchy.
