Printer

class Printer(val endpoint: PrinterEndpoint, val paperWidth: PaperWidth = PaperWidth.MM_80, val connectTimeoutMs: Long = DEFAULT_CONNECT_TIMEOUT_MS, val ioTimeoutMs: Long = DEFAULT_IO_TIMEOUT_MS, context: PrinterContext? = null, logger: PrinterLogger = PrinterLogger.NoOp, val connectionFactory: ConnectionFactory = DefaultConnectionFactory(logger))

Transport-agnostic thermal printer client. Built around a sealed PrinterEndpoint so the same code drives a network-attached printer, a BLE printer, or any future transport.

Each print, queryStatus, queryDeviceInfo, or kickCashDrawer call opens a fresh PrinterConnection via connectionFactory, performs the operation, and closes it.

Thread-safety: a single instance is safe to call from multiple coroutines; operations are serialized through an internal mutex so two callers cannot interleave bytes on the same endpoint. If you need true parallelism to the same printer (rare — most thermal printers cannot interleave jobs anyway), construct one Printer per coroutine.

Parameters

endpoint

Where to reach the printer (PrinterEndpoint.Network / PrinterEndpoint.Ble).

paperWidth

Receipt width — drives line wrapping in ReceiptBuilder.

context

Platform handle. Required for PrinterEndpoint.Ble endpoints (Android Context, iOS shared CBCentralManager). Ignored for PrinterEndpoint.Network — pass null or omit.

logger

Optional PrinterLogger for breadcrumbs from the BLE / TCP transports. Defaults to PrinterLogger.NoOp — the library writes nothing to system log unless the consumer supplies a sink. Forwarded to DefaultConnectionFactory automatically; ignored if connectionFactory is overridden.

connectionFactory

Override only for tests — defaults to DefaultConnectionFactory wired with logger. Custom factories own their own logging.

suspend fun queryDeviceInfo(): DeviceInfo

Query printer identity via ESC/POS GS I n (manufacturer, model, firmware, serial). Returns a DeviceInfo with whatever fields the printer responded to — isEmpty is true when the printer ignored every query (typical for BLE printers). Transport failures (connect, write, genuine read errors) propagate as PrinterException.
