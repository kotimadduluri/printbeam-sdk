finalDrainMs

val finalDrainMs: Long = 500

Time the connection is held open after the last chunk is queued, before the caller's finally { close() } tears down the GATT. Without this delay the radio + printer buffer drop the tail of long receipts. Ignored for WRITE_WITH_RESPONSE.

maxChunkBytes
Link copied to clipboard
val maxChunkBytes: Int = 100

Hard cap on bytes per characteristic write, regardless of negotiated MTU. Cheap ESC/POS BLE chips often have ≤ 1 KB input buffers and overflow silently with full-MTU writes — the default 100 is tuned for the GoodCom / RPP02N class. Drop to 60 if a specific printer still truncates. Star and Bixolon happily accept higher.

mtu
Link copied to clipboard
val mtu: Int = 180

Requested MTU in bytes. Effective payload per write is mtu - 3 (ATT header). Default 180 keeps payloads ≈ 157 bytes which is well under most printers' rx buffer.

val writePaceMs: Long = 20

Delay between fire-and-forget WRITE_NO_RESPONSE chunks, in milliseconds. Gives the local BLE stack queue + the printer's input buffer breathing room. Ignored when the resolved characteristic uses WRITE_WITH_RESPONSE — those already serialize via the GATT ack callback.
