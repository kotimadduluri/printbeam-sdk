code
Link copied to clipboard
val code: String

Stable snake_case identifier for the failure kind (e.g. "connect_failed", "timeout"). Codes are stable API intended for programmatic matching — especially across the Obj-C bridge, where Kotlin subtype identity is fragile (is-checks against bridged exception classes don't work reliably from Swift). Match on code instead of the class name when the consumer isn't Kotlin.
