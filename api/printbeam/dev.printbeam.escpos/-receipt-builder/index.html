ReceiptBuilder

class ReceiptBuilder(paperWidth: PaperWidth = PaperWidth.MM_80)

Fluent DSL for assembling a thermal receipt. Each call appends the corresponding ESC/POS bytes to an internal buffer; the buffer is flushed in a single transport write when the enclosing Printer.print { … } block completes.

Also usable standalone, without a Printer: build the receipt offline, cache the encoded bytes, and send them later via Printer.sendRaw — useful for pre-rendering receipts before a connection exists, or for printing the same job to several printers.

val receipt = ReceiptBuilder(PaperWidth.MM_80).apply {
    text("MY STORE")
    cut()
}.toBytes()
// …later, possibly repeatedly…
printer.sendRaw(receipt)
