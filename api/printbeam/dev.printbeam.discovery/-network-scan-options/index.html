val concurrency: Int = 16

Max in-flight TCP connects during the port scan. Defaults to 16 to keep the SYN burst rate gentle on enterprise / hotel / captive networks; raise on dedicated POS LANs if scan latency matters more than network politeness.

enablePortScan

val enablePortScan: Boolean = true

When false the /24 port-scan branch is skipped and only mDNS runs. Recommended off for apps that ship to BYO-network environments (hospitality, retail kiosks on customer Wi-Fi) where 253-host SYN scans trip IDS / NAC enforcement.
