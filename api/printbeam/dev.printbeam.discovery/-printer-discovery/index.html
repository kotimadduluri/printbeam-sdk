PrinterDiscovery

interface PrinterDiscovery

Streams DiscoveryEvents from a printer scan — found-printers as DiscoveryEvent.Found and per-transport failures as DiscoveryEvent.TransportFailed.

Implementations must guarantee:

  • The returned Flow is cold: starting collection begins the scan; cancelling it stops the scan.

  • De-duplication of DiscoveryEvent.Found by printer.id — each unique endpoint is emitted at most once.

  • Clean resource teardown (mDNS listeners deregistered, BLE scans stopped, sockets closed) on cancellation.

  • At most one DiscoveryEvent.TransportFailed per transport per scan — emitted before the flow completes so the UI can distinguish "nothing found" from "scan never ran".

Parameters

transports

Which transports to scan. Default is all transports the platform supports; pass setOf(Transport.NETWORK) or setOf(Transport.BLE) to scope a single medium.
