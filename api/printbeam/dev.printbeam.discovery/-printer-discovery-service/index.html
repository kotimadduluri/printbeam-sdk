PrinterDiscoveryService

class PrinterDiscoveryService : PrinterDiscovery

Multi-transport printer discovery. Pass a Set<Transport> to discover to scope the scan to a subset of media; the default Transport.entries.toSet() scans everything the platform supports.

Construction is platform-specific because Android needs a Context:

// Android
val discovery = PrinterDiscoveryService(PrinterContext(applicationContext))

// iOS
let discovery = PrinterDiscoveryService(context: PrinterContext())

The returned Flow is cold: starting collection begins the scan; cancelling stops it. Found-printer events are de-duplicated by DiscoveredPrinter.id, which is endpoint-scheme-aware so network and BLE entries cannot collide.

Per-transport failures (e.g. BLE permission denied) arrive as DiscoveryEvent.TransportFailed rather than terminating the whole flow — the other transports keep scanning. Consumers that only care about results can .filterIsInstance<DiscoveryEvent.Found>().map { it.printer }.
