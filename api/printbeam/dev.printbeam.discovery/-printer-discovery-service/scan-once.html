scanOnce

suspend fun scanOnce(timeout: <Error class: unknown class> = DEFAULT_TIMEOUT, transports: Set<Transport> = Transport.entries.toSet()): List<DiscoveredPrinter>

Run a single scan to completion and return the deduplicated list of printers found.

Convenience over discover for callers that don't want to consume a Flow themselves — specifically Swift consumers of the iOS XCFramework, where Kotlin Flow bridging is verbose. Internally collects DiscoveryEvent.Found until timeout elapses.

Failure semantics: if at least one requested transport completed (even with zero printers found), partial DiscoveryEvent.TransportFaileds are absorbed and the list is returned — use discover directly if you need per-transport failures surfaced. If every requested transport failed and nothing was found, the first failure's PrinterException is thrown so total failure (e.g. all permissions missing) is not indistinguishable from "no printers nearby".

Return

List of unique DiscoveredPrinters in the order they were first observed (after enrichment), each one carrying the merged best-known fields for its endpoint.

suspend fun scanOnce(timeoutMs: Long, transports: Set<Transport> = Transport.entries.toSet()): List<DiscoveredPrinter>

Millisecond overload of scanOnce. Exists because kotlin.time.Duration is an inline class that bridges to Swift as an opaque Int64 of internal storage — Swift callers can pass timeoutMs: 6000 here instead of trying to construct a Duration from native code.
