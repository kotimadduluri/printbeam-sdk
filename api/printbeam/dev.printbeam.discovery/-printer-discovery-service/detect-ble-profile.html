printbeam/dev.printbeam.discovery/PrinterDiscoveryService/detectBleProfile

detectBleProfile

suspend fun detectBleProfile(endpoint: PrinterEndpoint.Ble, connectTimeoutMs: Long): BleProfile?

Open a brief connection to a manually entered BLE printer and identify which named BleProfile (Nordic UART / Star / generic 0xFF00) its GATT tree exposes. Useful for the "I have a MAC, but I don't know which profile to use" path in a settings UI.

Returns the matching profile when one of the known service UUIDs is exposed, or null when none match. A null return doesn't mean the printer won't work — dev.printbeam.Printer still auto-detects a writable characteristic at connect time — only that the consumer has no recognizable profile name to persist alongside the deviceId.

Propagates the same PrinterExceptions as a normal printer open (permission denied, Bluetooth off, timeout, peripheral not reachable). The connection is closed before this function returns, regardless of outcome.

Parameters

endpoint

The BLE endpoint to probe — endpoint.profile is ignored; this function only looks at the device's actual exposed services.

connectTimeoutMs

Hard deadline for the probe. Defaults to 5 seconds — long enough for a healthy printer to advertise + connect + enumerate services, short enough that a bad MAC fails fast.
