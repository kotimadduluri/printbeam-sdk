DiscoveryEvent

sealed interface DiscoveryEvent

One observation from a PrinterDiscovery scan.

Splitting found-printer notifications from per-transport failures lets the UI distinguish "no Wi-Fi printers found" (a Found never arrived for Transport.NETWORK) from "we couldn't scan Wi-Fi at all" (a TransportFailed arrived for Transport.NETWORK). Previously a per-source failure was swallowed silently and the user just saw an empty list — common when a consumer forgot to request BLE permissions.
