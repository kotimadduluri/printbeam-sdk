printbeam/dev.printbeam.discovery/BleScanOptions

BleScanOptions

data class BleScanOptions(val advertisedServices: List<String> = DEFAULT_PRINTER_SERVICE_UUIDS, val nameContains: List<String> = DEFAULT_PRINTER_NAME_HINTS)

Tunables for the BLE scan branch of dev.printbeam.discovery.PrinterDiscoveryService.

BLE radios advertise dozens of unrelated devices in a typical office — phones, earbuds, smartwatches, beacons. The defaults below narrow results to advertisements that look like thermal printers, on a union basis: a device is kept if it either advertises one of the known printer service UUIDs OR its name contains one of the known printer-keyword substrings.

The UUID list catches printers whose chips advertise correctly (Nordic UART, Star, the 0xFF00 generic family, etc.). The name list catches printers whose chips hide the service UUID until after the GATT connection — common for Epson TM-P20 / TM-P60II / TM-P80, Brother RJ / QL, Zebra ZQ, and other brand-named hardware that just identifies itself by name in the advertisement.

To opt out entirely (diagnostic / unknown-hardware mode), pass both lists empty — BleScanOptions(advertisedServices = emptyList(), nameContains = emptyList()) — and the scan will emit every BLE peripheral in range.

Filtering is done client-side, not via an OS-level ScanFilter. A 12 s foreground scan doesn't benefit meaningfully from the radio rejecting ads, and pushing it client-side lets the UUID OR name union work without losing devices to the radio filter.

advertisedServices
Link copied to clipboard
val advertisedServices: List<String>

Service UUIDs that mark a device as a printer. Defaults cover Nordic UART (Bixolon SPP-R200III, Xprinter XP-P323B, no-name 58 mm), Star Micronics' BLE GATT profile (SM-L200 and similar — NOT the TSP100IIIBI, which uses MFi/BT-Classic and isn't supported), the generic 0xFF00 service (GoodCom / RPP02N), HM-10 modules (0xFFE0), and Bixolon's 0x18F0.

nameContains
Link copied to clipboard
val nameContains: List<String>

Case-insensitive substrings matched against the advertised local name as a fallback for printers that don't advertise a known service UUID. Defaults to a curated list of brand and product-line keywords.
